# Static RAM, reachability and timing analysis

Scope: exact frozen RC3, B and D, both TV formats. Source statements refer to the generated bank0–3 ASM/listings/symbol files preserved in the previous checkpoint and independently reproduced CI artifacts. The claims are conditional on ordinary F6 cartridge execution, reset through F6Boot, documented input, and valid gameplay state, not arbitrary external corruption, electrical faults, or newly allocated RAM.

## Alias lifetime and address domains

The D symbols define digit = lane = $A8. The six bytes $A8–AD are digit[0..5] in bank 2 and lane, p0ptr low/high, p1ptr low/high, gateMid in bank 1. laneWater follows at $AE; h1..h4 and lifeL/R are independent allocations. ramEnd=$DB, hence unallocated $DB–E7 (13 bytes vs 7 in RC3/B); E8–FF reserved for stack. RC3/B digit occupies a separate six-byte interval. Bank0 gameplay reads neither group as live gameplay data; identical logical RAM variable order after projecting out legacy digit bytes.

Frame: bank1 sets VBLANK, runs two positioning calls, F6HUD selects bank2. PrepareHUD either jumps HUDPresent after cache match, or stores six digit offsets from packed valid BCD score/current sessionBest. Times5 indices 0..9. PrepRow has Y=0..4; offsets initially 0,5,..45, incremented once each row, hence reads 0..49; terminal 5..50 never indexed. All six writes dominate first reads and RMW accesses. h1..h4 and lifeL/R preserve cached pixels; cache hit skips all digit reads/writes. Presentation uses objectPtr[0..3] and title glyphs independently. F6HUD returns to bank1. WaitVB does not use digit. Before LaneStart, lane is initialized to zero; four iterations 0..3, terminal 4. Each LaneStart writes p0ptr low (Blank or pose KeeperTable), high=$F9; writes p1ptr high=$F9 and low from objectPtr; then computes gateMid 0/2 before ObjectRows. ObjectRows Y=0..9, pointers fixed until ten rows complete. The next lane redefines both pointers and gateMid; loop increment reads defined lane. No call into bank2 or bank0 during visible kernel; overscan calls F6Logic bank0 only. A HUD cache hit needs no preserved digit. Reset enters F6Boot -> bank0 Reset (SEI/CLD/SP=$FF; clears all zero page, including TIA mirror writes); soft RESET NewGame resets hudValid and data but does not read alias. Every return uses shared F6 trampolines. All four reset vectors were traversed by prior CFG, 8-byte max modeled and observed; E8–FF retained. The boot clear is intentional and excluded from runtime nonstack allocation claims.

## Range analysis

Inductive source invariants: NewGame active=2 or4, level=1 or7, lives=3, keeper=0, speed=1 or2; level saturates at255, active increments only while <4, keeper moves only within [0,active-1]; lives decrement only in gameplay from positive, Game Over sets mode=2 and no further object movement, bonus increments only if <3. mode 0/1/2, variant 0/1, pose 0/1/2. kind[0..3] initializes 0, spawns 1/2, success transitions to 3/4, error 5/6, retires to0. No other kind writes. pos initializes 8; stepSpeed 1..3; when position reaches >=129 retire, retaining 129..131 only as empty lane. Active normal object gate at 112..114, hit sprites use fixed 112; no 8-bit overflow. phase skip NTSC does not change inter-lane relationships. motionPhase modulo256 toggles parity. priority=0..6, event indices Y=0..6 and input sound Y=0..2; EventSound conditional priority updates. flashLane derives from X 0..3. gates toggles Mask[keeper] with masks 1/2/4/8, so [0,15]. level>>2 &3 gives 0..3. h1..4 indices 0..4; masks, kind, pos, delay, InitialDelay, objectPtr indices 0..3; Lives tables X 0..3; KeeperTable Y 0..2; ObjColor/BasePtr Y 0..6; AltPtr only 1/2; Title/Expert rows X 0..4. HMP0 and RESP0 indexed by 0,4 for HUD positioning and 1 for lane positioning. Indirect reads (p0ptr),Y/(p1ptr),Y: sprite bases within $F900–F98C; row0..9 yields <=$F995; no page crossing, no F6 hotspot. Valid BCD is inductive: start=0; SED + fixed decimal increments 25/100/500 on three packed bytes; carry past sixth digit clamps all to $99; CLD before return; best updated by bytewise unsigned BCD comparison. Only these score writes; sessionBest zero at cold reset, preserved by NewGame. Table bounds therefore follow from valid state; forced tests which deliberately violate cross-variable reachability are not counted as natural proof.

`indexed_effective.py` verifies each complete observed indexed instruction's effective address from encoded operand and pre-instruction X/Y. It distinguishes opcode fetch/operand reads, semantic data reads, first RMW physical write of old value, final writes, dummy reads (including page-cross wrong-page read), and verifies actual CPU addresses. RIOT RAM decoding uses physical A0..A12, `(a & $1280)==$0080`, physical offset a&$7F. Stack accesses at $01xx mirror RIOT RAM; observed stack pushes F8..FF and dummy stack access may touch F7, within reservation. Direct indexed boot clear starts at zero, X=255..1 (plus unindexed $00), dummy reads of TIA addresses occur; runtime dummy reads at zero-page indexed base or wrong ROM page are classified rather than treated as use-before-def. No runtime dummy access to F6 hotspot, INTIM, or unallocated RAM was observed. TIA reads are input/collision read registers, not writes to mirrored write registers; no dummy runtime write to TIA in this source; TIA clear/write side effects at boot are intended. Raw access logs retained. Source bounds and site coverage are explicit, not an exhaustive abstract-interpretation theorem of every data byte. New core equivalence to previously uninstrumented core checked with 720 fixed inputs per TV, plus 5 deliberately mutated ROM oracles.

## Natural single-outcome invariant (shared bank0)

1. Update processes at most four lanes each logical tick. At most one spawn per tick: spawnGap decrements once before the lane loop, and SpawnReady sets it to 12 if level<12, 8 otherwise. NewGame clears all objects; ClearObjects after a mistake destroys both pending objects, so no pair can survive a reset/mistake. A normal pending kind1/2 starts at position 8; advances 1..3 each tick until first gate resolution at >=112. A previous normal object that survives until a subsequent spawn has at least 12 position units lead after that spawn tick: gap 12 and step>=1, or gap 8 at level>=12 where step>=2 (lead>=16). If the previous object resolves in that tick, the later spawn is at8, not at the gate.
2. Assume two distinct objects could both resolve in the same later tick, with no intervening clear. From newer spawn until that tick is at most 104 moving ticks (1 minimum step). Other already-pending objects occupy at most two remaining lanes; they contribute at most two outcomes. New objects spawned after the newer one need at least ceil(104/3)=35 moving ticks to reach the gate, and can spawn only at +8,+16,...,+64 (at most eight) before the last possible common tick. Thus at most 2+8+2=12 outcomes, including the pair itself (conservative). Each round rollover consumes the outstanding roundN >=1 then resets it to8; within 12 outcomes, at most two level transitions. Level is nondecreasing until reset; at cap it does not change. This argument does not assume the conclusion; it uses only spawn spacing and the maximum four slots.
3. For a fixed level and fixed speed, any two still-normal objects have equal displacement per tick except at level>=12 with alternating lane parity, where per-tick difference is at most1 and cancels every two ticks (motionPhase increments once per logical tick). For a contiguous block, relative displacement can shrink by at most1. With at most two level transitions, at most three such blocks, plus at most two transition ticks where one object may be processed before level/speed changes and the other after; each such mixed tick can shrink lead by at most2 (steps within 1..3). Total possible shrink <=3+4=7. Initial lead>=12, so at alleged common resolution tick lead>=5. Both resolving positions must lie in 112..114, a difference <=2. Contradiction. If a mistake occurs earlier in that same tick it clears all pending objects, which also prevents a second gate outcome. Thus at most one CountOutcome call per normally reached tick. This is a source-level conditional proof; if future changes alter spawnGap, stepSpeed, level progression, count or object lifetime, re-evaluate immediately.
4. Forced simultaneous four-object matrices intentionally bypass this invariant. Exactly two of 2304 NTSC adversarial combinations give 263 lines in RC3 and D; fresh traces reproduce them also in B. Both have four normal objects at pos111 and four successes, clean round rollover, all score bytes $99, FIRE+UP and levels12/252. First overscan poll elapsed2193 cycles (48 before underflow); nominal <2 exit was missed at the preceding scanline because Update took too long, so the wait ends one scanline later. No INTIM underflow, but one-line frame-length error. This is real forced-state timing behavior, not a naturally demonstrated bug or D regression. Retain as shared robustness warning (SP-VER-011).

## CPU and TIA budget

`wcet.py`: emitted opcodes/listing verified against ROM; conservative dynamic programming branches both directions except explicit immediate conditions and justified source invariants; loop maxima: object four, ClearObjects four each invocation, Position two calls with at most 15 taken subtraction branches combined (133 and 118), PrepRow five, ArtLoop four, title glyph loops five. At most one round rollover per frame even in four-outcome overapproximation. Conservative +76 cycles for every WSYNC stall; actual absolute-index page-cross cost bounded by source ranges; conditional branch taken costs3/4 depending on page. Sound priority lower bound via event Y; NewGame paths cannot reach movement after title reset. Natural mode applies proven <=1 CountOutcome per tick. Unrestricted four-outcome overscan static bound may exceed timer; this is retained, not silently suppressed. First INTIM margin uses timer expiry load*64+1 (M6532 sets divider-1); static first-read bound safely earlier than the last two timer ticks. Polls once each raster line (76 cycles); threshold <2 spans128 cycles, so with first poll before this window it cannot be skipped. Frame deadline is anchored to WSYNC, not just measured elapsed line count. See all six `WCET_NATURAL*` results and unrestricted `WCET_*` results. D NTSC conservative first read <=1942 VB and1577 OS, slack811/664. PAL <=1942/1564, slack2731/2533. RC3 VB bound1970, D/B1942; OS same. Beam and audio absolute write times compared in actual Stella; per-register windows from `visible_wcet.py`, all 48 WSYNC-site segments max67 cycles of76, incl LanePos <=8 taken branches at pos<=131. Thus nine cycles conservative segment slack. No claim of an independent full transistor-level TIA timing model; actual beam traces match, and native second emulator confirms output.

## Generator/fairness limits

Random recurrence `n -> (n>>1) xor ($B8 if low bit set)`, initialized $A7, has all255 nonzero states, zero absorbing but never reachable from nonzero seed. On title the real ROM advances exactly this recurrence, checked 520 callbacks for each TV and candidate. One-bit output counts 128/127 over cycle; ordered transitions 64,64,64,63; not independent random or cryptographic. Delay formulas 15..46 low level and 10..25 high level. One spawn at a time, at least 8 ticks separation, every pending object has at least35 moving ticks to gate; lane selection/release and FIRE can be controlled before arrival, gates persist. The single-outcome invariant rules out forced four-deadline collision; does not prove every possible controller history is recoverable, or fairness under limited reaction, or balance for human players. Image-only policy (8-frame reaction cadence, color/geometry calibrated) separately tested actual play; source code keeps RAM observational only, not policy input. Human/hardware still require separate tests.
