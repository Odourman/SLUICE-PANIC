# Riskregister
R1 HMOVE/RESP1 pixelkalibrering: hög, test x8, 14/15/16, 112, 128 och alla lanes; bankrader kan få 8-klockors svart hack som tolereras i prototyp, inte otestat i final. R2 PF HUD timing: hög, kontrollera färgklockor 0/79/80/159 samt 000000/888888/123456. R3 P0/Ball drift vid HMOVE: hög, logga konstant x efter varje lane. R4 Frame timing PAL/NTSC: hög, mät 1000 frames inkl reset; standard 312/262. R5 4KB/RAM: medium/hög, faktisk gameplay budget/stack high-water krävs. R6 färgläsbarhet/BW: medium, test fysisk CRT och PAL. R7 logisk kollisionsgräns vid hastighetshopp: medium, prov över x112 utan dubbla poäng. R8 no flicker: medium, jämför konsekutiva emulatorframes. R9 diagnostikens opcodeencoder är inte en oberoende assembler eller emulator: verifiera med DASM och Stella/Gopher. Ingen faktisk PASS utöver assetmodell och statiska assertions. Om problem: förenkla port/hud först; inga nya funktioner eller flimmer som dold workaround.
